## 📌 项目说明

**Awesome Telegram AI Bots（中文精选）** 专注收录 **Telegram AI 机器人**：AI 对话（ChatGPT、Claude、Gemini、DeepSeek、Grok 等）、AI 绘画与影像生成、AI 翻译与语言学习、AI 助手 / 语音 / 音乐。

收录标准：

- **逐一核验**：每个机器人都打开其 [t.me](https://t.me) 主页确认过——是机器人本体（有 Start Bot 入口）、运营方与功能说明与主页一致；已停运、主页不存在、只有名字没有说明的，一律不收
- **标注来源**：官方机器人与第三方接入分开注明；不存在的「官方」名头绝不乱标（例如 Midjourney 并没有官方 Telegram 机器人，市面上的都是第三方）
- **附月活参考**：主页显示月活跃用户数的会一并记录，方便判断热度
- **最近核验日期：2026-10-31**

找其他品类（群管理、资源搜索、下载、频道运营……），请看主项目总榜：**[Awesome Telegram Bots CN](https://github.com/Armorys/awesome-telegram-bots-cn)**（网页版：https://armorys.github.io/awesome-telegram-bots-cn/ ）。

## 如何判断 AI 机器人是否靠谱

- **先认清「官方」**：OpenAI **没有**官方 Telegram 机器人，ChatGPT 的官方入口只有官网与官方 App；DeepSeek、Claude、Gemini 同样没有官方机器人，自称官方的多为第三方接入。本列表中注明官方的（如 Microsoft Copilot、Perplexity）均为主页带 ✔ 认证的账号，其余一律按第三方看待。
- **付费先小额试用**：聚合类机器人大多是「免费额度 + 付费订阅」，先把免费额度用明白，确认效果再付费，不要一上来就充大额或买长期套餐。
- **不输入敏感信息**：不要在机器人对话里发送密码、验证码、银行卡号、私人文件；你上传的照片和文档，等于交到了第三方服务器上。
- **认准用户名再点**：热门机器人有大量仿冒号（多一个下划线、换一个字母）。从本列表的链接进入最稳妥，使用前再核对一次用户名拼写。

## 常见问题（FAQ）

**Q：Telegram 有官方 ChatGPT 机器人吗？**
A：没有。OpenAI 未推出官方 Telegram 机器人；所有名为 ChatGPT 的机器人都是第三方接入。本列表里的 Microsoft Copilot（@CopilotOfficialBot）与 Perplexity（@askplexbot）则是各自公司官方推出的，主页带 ✔ 认证。

**Q：免费 AI 绘画用哪个？**
A：先试 @AIImageBot、@stable_diffusion_bot 免费起步；想体验 Midjourney 风格可用 @midjourneyfreebot（第三方，有免费额度）；聚合类的 @GPT4Telegrambot、@syntxaibot 也带免费额度，具体规则以机器人内说明为准。

**Q：AI 机器人要付费吗？**
A：大多数是免费 + 付费混合：日常轻度使用免费额度通常够用，最新模型、高清出图、长对话一般要订阅或购买额度。建议先小额试用再决定。

**Q：怎么把 AI 机器人加到群组？**
A：在群组设置里「添加成员」，搜索机器人用户名添加即可；翻译类的 @TransChat_bot、@TgTranslatorBot 添加后按提示授权即可自动翻译；@dalle_query_bot 这类支持 inline 模式，在任意对话输入 @用户名 就能调用。详细步骤见主项目的[如何把机器人加到群组](https://github.com/Armorys/awesome-telegram-bots-cn#如何把机器人加到群组)。

**Q：AI 机器人回答的内容准确吗？**
A：不一定。AI 会一本正经地编造（幻觉），重要信息务必核对原始来源；需要查证的问答，优先选 @askplexbot 这类联网检索型机器人。
